# 启动开发环境 + 逐步搭建你的小岛

## 第一步：启动开发环境（本次批准后立即执行）
- 在后台运行 `python3 tools/serve.py`：它会自动挑一个空闲端口、在终端打印地址、并自动打开浏览器。
- 确认服务正常启动、页面能加载，然后把本地地址发给你。
- 你在浏览器里看到的就是当前的"空白草地岛"——这就是我们重新构建的画布。

## 第二步：一步步构建小岛（之后按你的反馈迭代）
每次改动只涉及你自己的世界文件，不动引擎：
- `world/layout.js` — 岛的范围、出生点、站点（卡片交互点）、建筑/传送门位置等数据
- `world/build.js` — 用代码搭地形、建筑、家具、植物
- 需要时同步更新 `index.html` 的卡片内容和 `home.config.js` 站点设置

建议的搭建顺序（可随时调整，每完成一步你刷新浏览器看效果）：
1. **定基础** — 岛的大小与地形、出生点、各站点分布
2. **主体建筑** — 房子/工作室的外观
3. **卡片站点** — 把"关于我/作品/联系"等站点落位，对应 index.html 卡片
4. **室内与灯光** — 家具布置，灯光写入 bakes（烘焙光照）
5. **景观** — 树、花草、小径、宠物等点缀

每步做完用 `?debug` 叠层或 `npm run check` 核对性能预算（绘制调用 ≤60、三角面 ≤20 万）并检查截图（`tools/.check/`）。建筑尺寸和材质参考 `examples/terry-home/` 的现成做法。
